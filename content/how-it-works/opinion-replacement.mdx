# Opinion Replacement Details

Opinion replacement is the mechanism that makes markets evolutionary. Let's understand exactly how it works.

## The Setup

### Two Pools

**Active Pool (AMM):**
- Hard cap: 10 opinions maximum
- Opinions have quantities and prices
- Trading happens here
- Limited slots create competition

**Candidate Pool:**
- Unlimited opinions allowed
- Opinions have accumulated stake
- No prices (not trading)
- Waiting area for entry

**The dynamic:** Candidates compete to enter. Active opinions defend their positions.

## The Replacement Condition

### When Replacement Can Happen

A candidate can replace the weakest active opinion when:

$$\text{Candidate stake} \geq (1 + \theta) \times \text{Weakest opinion's liquidation value}$$

Where:
- $\theta$ = Replacement threshold buffer (default: 0.05 = 5\%)
- Weakest = Opinion with lowest liquidation value among actives

**Example:**
- Weakest active opinion: Liquidation value $100
- Threshold: 1.05 × $100 = $105
- Candidate needs: $105+ to be eligible

### What is Liquidation Value?

**In plain language:** The money you'd get from selling all shares of an opinion.

**Formula (technical):**

$$V_i = \frac{q_i^2}{\|q\| + \sqrt{\|q\|^2 - q_i^2}}$$

**Roughly:** Proportional to $q^2$ (so low quantity = low liquidation value = vulnerable)

### The 5% Buffer (Threshold)

**Why it exists:** Prevents rapid flip-flopping.

**Without buffer:**
- Opinion A has $100 value
- Candidate B gets $100 stake, replaces A
- A now has $95 (lost value in replacement)
- Another candidate C gets $95, could immediately replace B
- Endless churn, instability

**With 5% buffer:**
- A has $100 value
- B needs $105 to replace A
- After replacement, A has ~$95
- B now has ~$105 value
- A would need ~$110 to replace B back
- Meaningful gap prevents immediate reversal

**Governance adjustable:** Can be set 0-20% based on desired market dynamics.

## The Replacement Process

### Step 1: Identification

**Who gets replaced:** Always the weakest active opinion (automatic).

**Not user's choice:** The contract determines weakest by liquidation value.

**This ensures fairness:** Can't target specific opinions. Pure economics.

**Example check:**
```
Active Opinions:
- Opinion A: Liquidation value $150
- Opinion B: Liquidation value $120
- Opinion C: Liquidation value $90  ← Weakest
- Opinion D: Liquidation value $105

Candidate X has $95 stake
Threshold: $90 × 1.05 = $94.50
Result: X is ELIGIBLE to replace C
```

### Step 2: Triggering

**Anyone can trigger** replacement if a candidate is eligible.

**How:**
1. Navigate to debate page
2. Click "Candidate Opinions" tab
3. See eligible candidates (highlighted)
4. Click "Replace Weakest Opinion"
5. Confirm transaction
6. Pay gas (~$0.10-0.30)

**Why anyone:** Permissionless. No special privilege needed.

**Incentive:** Enables your staked candidate to enter (if you're a stakeholder), or improves debate quality.

### Step 3: Exit Phase

**The weakest active opinion is removed:**

**Calculations:**
1. Identify opinion C (weakest, $q_C = 15$ units)
2. Calculate total cost: $C = \|q\| = \sqrt{\sum_i q_i^2} = 50$
3. Calculate liquidation value: $V_C = \frac{q_C^2}{C + \sqrt{C^2 - q_C^2}} = 90$
4. Remove C from active pool
5. Set $q_C = 0$
6. New cost: $C' = \sqrt{\sum_{i \neq C} q_i^2} = 47$

**What happens to C's shareholders:**
- Share counts unchanged: userShares[alice][C] still = 100
- Interpretation changes: Now represents claim on $90 candidate stake
- If Alice owned 10% of C, she now has claim on $9
- Automatic, no action needed

**C becomes a candidate:**
- Joins candidate pool
- Starts with accumulated stake = $90
- Can accumulate more stake
- Can potentially re-enter later

### Step 4: Entry Phase

**The candidate X enters the AMM:**

**Calculations:**
1. Candidate X has stake $M_X = 95$
2. Current cost after exit: $C' = 47$
3. Calculate entry quantity: $q_X = \sqrt{M_X \times (2C' + M_X)} = 13.4$ units
4. Add X to active pool with $q_X = 13.4$
5. New cost: $C'' = \sqrt{(C')^2 + q_X^2} = C' + M_X = 47 + 95 = 142$

**What happens to X's stakers:**
- Share counts unchanged: userShares[bob][X] still = 50
- Interpretation changes: Now represents claim on 13.4 AMM units
- If Bob owned 20% of candidate X, he now owns 20% of 13.4 = 2.68 units
- At new price 0.38: Worth 2.68 × 0.38 = $1.02
- Automatic, no action needed

**X is now active:**
- Has quantity and price
- Can be traded
- Competes with other actives

### Step 5: Update

**System updates:**
- Active opinion list: Remove C, add X
- Opinion states: C → CANDIDATE, X → ACTIVE
- Prices recalculate (all opinions affected slightly)
- Event emitted with full details

**Net vault change:** C'' - C = M_X - V_C = $95 - $90 = $5 (vault grew)

## Mathematical Properties

### Value Conservation

**Before replacement:**
Total value = Active vault (C) + Candidate stakes (including M_X)

**After replacement:**
Total value = Active vault (C'') + Candidate stakes (including V_C)

**The math:**
C'' = C - V_C + M_X (vault changes)
Candidate stakes: -M_X + V_C (X removed, C added)

**Net change:** Zero (modulo rounding)

**Property:** Replacements don't create or destroy value.

### Gas Efficiency

**Key insight:** No loops over shareholders.

**The magic:**
- Share counts don't change
- Only opinion-level state changes
- O(1) complexity regardless of shareholder count

**This means:**
- Opinion with 10,000 holders: Same gas as 10 holders
- Scalable to any size
- No migration transactions

**Why this matters:** Makes dynamic markets practical.

## User Experience

### For Exiting Opinion's Holders

**What you experience:**

1. **Notification:** "Opinion C moved to candidate pool"
2. **Position update:** Profile shows "Candidate" badge
3. **Value display:** "$9.00 staked" (was "3.5 units at $2.57")
4. **Options:** Unstake now, hold for comeback

**What you might feel:**
- Disappointed (opinion lost active status)
- Uncertain (will it come back?)
- Urgency (should I exit now?)

**What you should know:**
- Your proportional ownership preserved
- Opinion can re-enter if support builds
- No deadline to decide
- This is normal market evolution

### For Entering Opinion's Stakers

**What you experience:**

1. **Notification:** "Opinion X entered the AMM"
2. **Position update:** Profile shows "Active" badge
3. **Value display:** "2.68 units at $1.02" (was "$19 staked")
4. **Options:** Trade normally, hold, sell

**What you might feel:**
- Excited (opinion made it!)
- Hopeful (price could rise)
- Proud (you were right to support it)

**What you should know:**
- Opinion now competes actively
- Price will fluctuate with trading
- Could get replaced later
- Success isn't guaranteed

### For Other Active Opinion Holders

**What you experience:**

1. **Notification:** "Replacement occurred"
2. **Price update:** Your opinion's price adjusted slightly
3. **Market composition changed**

**Impact:**
- Usually minimal
- All active opinions' prices shift slightly due to new composition
- Your shares unchanged
- Just continue as before

## Edge Cases and Special Situations

### Multiple Eligible Candidates

**Scenario:** Two candidates both above threshold

**Resolution:** First one triggered gets replaced. Race condition.

**In practice:** Whoever clicks "Replace" first wins. Gas price matters.

### Threshold Changes

**Scenario:** Weakest opinion's value changing while candidate accumulating

**Impact:**
- Threshold is dynamic (105% of current weakest)
- Candidate might be eligible one moment, not the next
- Progress bar updates in real-time

**Strategy:** Candidate supporters monitor and coordinate to reach moving target

### Replacement During Settlement Approach

**Scenario:** Debate has 3/4 settlement criteria met, replacement happens

**Impact:**
- Resets settlement progress (composition changed)
- Prices adjust, likely affects variance
- Settlement delayed

**Rare:** Usually near-settled debates have stable composition

### Simultaneous Replacements

**Scenario:** Multiple replacements in quick succession

**Prevention:** Each replacement must be separate transaction

**Impact:** Market composition evolves rapidly, prices volatile

**Governance:** Could implement cooldown between replacements (optional mechanism)

## Strategic Considerations

### For Active Opinion Holders

**Monitor your opinion's vulnerability:**
- Check its liquidation value vs. others
- If weakest, watch candidate pool
- Consider buying more to increase liquidation value (defend position)

**Defense mechanisms:**
- Buy shares → increases q → increases liquidation value
- Gets harder to replace
- Natural protection through support

### For Candidate Stakeholders

**Getting over threshold:**
- Coordinate with other believers
- Time stakes for maximum effect
- Promote opinion to attract more stakes

**Watch the weakest target:**
- Threshold changes as weakest changes
- Strategic timing: stake when weakest is low
- Efficiency: easier to replace weak opinions

### For Replacement Triggers

**Who should trigger:**
- Candidate stakeholders (most incentive)
- Debate participants (improve quality)
- Anyone (permissionless)

**Gas consideration:**
- Small cost ($0.10-0.30)
- Worth it if you're a stakeholder
- Or if you value debate quality

## Tracking Replacements

### In the UI

**Debate page shows:**
- "Activity" tab: All replacement events
- Timeline annotations
- Before/after compositions
- Affected users count

**Opinion pages show:**
- Lifecycle history
- Dates active/candidate
- Number of times replaced
- Number of times re-entered
- "Battle-tested" opinions (cycled multiple times)

### Onchain Events

**Every replacement emits:**
```solidity
event OpinionReplaced(
  uint256 indexed debateId,
  uint256 indexed exitingOpinionId,
  uint256 indexed enteringOpinionId,
  uint256 exitLiquidationValue,
  uint256 entryStakeUsed,
  uint256 affectedUsers,
  uint256 timestamp
);
```

**Full audit trail** of all replacements forever.

## Why This Design

### Benefits

**1. Evolutionary markets**
- Debates adapt to new information
- Better perspectives can emerge
- Bad framings get corrected

**2. Meritocratic**
- Economic support determines inclusion
- No subjective gatekeeping
- Pure market dynamics

**3. Scalable**
- O(1) gas regardless of shareholders
- No migration transactions
- Handles any debate size

**4. Continuous ownership**
- Users maintain economic interest
- No forced exits
- Proportional claims preserve fairness

**5. Dynamic equilibrium**
- 10-opinion cap creates competition
- Threshold buffer prevents chaos
- Natural selection for quality

### Trade-offs

**Complexity:**
- Users must understand proportional claims
- Two-state system less familiar
- Requires education

**Volatility:**
- Replacements can affect prices
- Position values change with state
- Some uncertainty

**Worth it:** The benefits of evolutionary markets outweigh the complexity.
